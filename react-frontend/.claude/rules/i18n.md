# Language & i18n

- `store/language-store.ts`: `en`/`vi`, sets `<html lang>`. Consume strings via the exported `useT()` hook — deliberately not a store method, so relabels re-render.
- `app/i18n/translations.ts`: `en` is the source of truth; `vi` is typed as the full key map, so a missing translation fails `npm run build`.
